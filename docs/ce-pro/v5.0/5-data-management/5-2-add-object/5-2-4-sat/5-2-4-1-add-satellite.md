# Add Satellite

> **Applies to:** SAT.

Satellites are not placed on the map with a dedicated Add Object dialog. Instead, satellites are managed as templates in the [Template Manager](../../5-8-template-manager.md), under the **Satellite Templates** group in the **Network Objects** tab.

Satellite templates can be edited or duplicated to create new templates for use in the [Quick SAT Link Budget](../../../7-coverage-prediction/7-3-sat/7-3-1-quick-sat-link-budget.md) and [Sky Clearance](../../../7-coverage-prediction/7-3-sat/7-3-2-sky-clearance.md) tools, when the **GEO** satellite type is selected.
