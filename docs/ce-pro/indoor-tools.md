# Indoor Tools

Indoor uses the same common CE Desktop Pro workflow as every other module — Overview, Geographic Data, Workspace, Data Management, Profile, and Coverage Prediction all apply exactly as described in those sections.

The one Indoor-specific step is creating an **Indoor Workspace** from a CAD drawing — see [Indoor Workspace](#ce-pro-indoor-workspace) under the Workspace section for that flow.

There is no additional Indoor-specific tooling beyond this at the moment. If Indoor-only features are added to the product in the future, document them on this page.
